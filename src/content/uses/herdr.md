Herdr is where my agents live. Each project gets a named session with its panes and tabs, so I can detach, come back hours later, and pick up exactly where the agents left off.

It doubles as my agent orchestrator. Claude Code and Oh My Pi run side by side in their own panes, one agent can read another's output or hand off work to it, and I watch the whole fleet from one window instead of juggling terminal tabs.
