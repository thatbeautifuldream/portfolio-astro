मेरा ज़्यादातर दोहराव वाला इंजीनियरिंग काम अब Claude Code से होकर गुज़रता है। यह कोडबेस पढ़ता है, सटीक बदलाव करता है और वेरिफ़िकेशन लूप चलाता है, ताकि मेरा ध्यान प्रोडक्ट के फ़ैसलों पर टिका रहे।

यह पोर्टफ़ोलियो भी काफ़ी हद तक इसी से मेंटेन होता है।

मैं इसे [Herdr](/hi/uses/herdr) के अंदर चलाता हूँ, अक्सर दूसरे एजेंट्स के साथ जो पैरेलल में काम कर रहे होते हैं।
