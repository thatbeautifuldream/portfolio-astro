Oh My Pi sits next to Claude Code in my terminal. It brings editor-grade context like diagnostics and symbols into the agent loop, so changes land with fewer round trips.

I reach for it when I want a second agent working a different part of the codebase in parallel, with [Herdr](/uses/herdr) orchestrating the two.
